BIKINMEME API

Kirim URL gambar + teks, terima meme jadi. Cocok untuk project dan bot WhatsApp. ← Kembali ke generator

Endpoint

GET atau POST /api/meme — mengembalikan gambar (PNG secara default), atau JSON berisi base64 jika format=json.

Gratis, tanpa API key (kecuali pemilik situs mengaktifkannya). Hanya foto — video tidak didukung lewat API.

Coba langsung

Parameter

NamaDefaultKeterangan
url—URL gambar publik (http/https). Salah satu dari url / image / upload mentah wajib ada.
image—Gambar dalam base64 (boleh berawalan data:image/…;base64,), untuk POST JSON.
top, bottomkosongTeks atas / bawah, maks 200 karakter. \n = baris baru.
size11Ukuran teks (5–20, % lebar gambar).
outline14Tebal outline (0–30).
fill, strokeffffff, 000000Warna teks / outline dalam hex (3 atau 6 digit, tanpa # di URL).
uppertrueUbah teks jadi huruf kapital.
squarefalsePotong dari tengah jadi 1:1.
maxSide1024Sisi terpanjang hasil, 128–2048 px.
formatpngpng, jpg, webp, atau json.
quality90Kualitas jpg/webp (30–100).

Batas: gambar maks 8 MB. Error dikembalikan sebagai {"ok":false,"error":"…"} dengan status HTTP yang sesuai (400, 401, 403, 413, 415, 502, 504).
